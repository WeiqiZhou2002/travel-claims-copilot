# 当前状态

更新：2026-09-28。此文档是实现状态的唯一入口；历史审查保留在 archive。

## 本轮完成

- 事实抽取改为 LLM-only；删除 intake 正则 fallback 和字段覆盖合并。未配置或模型失败时停止本次抽取，保留输入；旧自由文本分析入口同样使用 LLM。
- 结构化 provider 仅做精确别名规范化，避免 United Kingdom 一类字符串被截成航司名。
- 本地审核与线上发布分离，线上只使用版本化 JSON；新增审核快照发布脚本，撤回通过下次导出部署生效。
- 审核限制为开发环境；文件锁记录 PID / 主机 / token，确认进程失效后串行恢复，不按固定时长抢锁。
- 保留原始 DP、人工编辑与审计记录；论坛 DP 使用稳定不透明 ID。历史本地存储读入时迁移 ID 引用，不清空人工审核。
- 首页抽出对话 hook 和结果区块；审核台消除组件间循环引用，加入统一格式工具。
- 政策增加复核到期提示；90 天为编辑周期，不是法规有效期。
- 清理 .DS_Store 和重复交接文档，保留产品边界、领域词汇和独立数据契约。

## 验证边界

本地自动化测试覆盖模型契约、错误恢复 API、审核事务、死进程锁回收、发布与撤回、发布失败保留旧文件、政策复核日期、检索和范围控制。

模型语义准确率评测单独由 `npm run eval:intake` 运行，会产生真实 API 调用。mock 测试只证明应用遵守模型返回值及校验契约，不证明模型理解能力。

## 本轮验证记录

- 119 项本地自动化测试通过；16 项外部模型评测默认不随单元测试运行。
- 在线评测一轮 24 项中 23 项通过，发现模型把旅客证件问题归为航司可控原因；提示词补充控制主体后，该回归单独重跑通过。模型行为仍有随机性，不把单次通过当成准确率保证。
- 数据校验覆盖 57 条案例，其中发布快照包含用户已审核的 2 条 DP；其余候选没有被自动批准。
- 首页浏览器验证完成了纯 LLM 抽取至分析展示；审核页确认保留 17 条待审、2 条已通过。
